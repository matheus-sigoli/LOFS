# ADR 0001 — Projeto acadêmico independente, sem marca oficial

- **Status:** Substituída pela ADR 0008 · 2026-10-31

## Contexto
O site trata dos campeonatos da Federação Paulista de Futsal, mas é um projeto acadêmico/portfólio sem autorização da FPFS.

## Decisão
- Identidade visual e nome próprios; nenhum uso de logo, nome comercial ou domínio que se passe pela FPFS.
- Rodapé e página "Sobre" com aviso: projeto independente, sem vínculo com a FPFS; dados de referência públicos.

## Consequências
- Liberdade total de design.
- Evita confusão com o canal oficial e problemas de marca.
